# Handoff: refuse orphan folders, split C4, build C5

C4's builder stopped with C4 implemented and green but uncommitted in the build worktree (notes:
`.claude/work/redo-main/build-c4.md`). The user settled the two questions it raised; the plan
(sections 2, 4, 6 and 7) is updated to match.

## Decided

- **A unit folder without `work.json` is refused, never deleted.** From C4 the folder holds the
  unit's session transcripts. `/shape`, with or without `--branch`, on such a folder notifies
  `Orphaned` at `error` before any checkout and writes nothing. The third C3 commit becomes
  `feat: /shape refuses a unit folder that has no work.json`: `Recreated` and
  `removeWorkUnitDir` go, and spec §2's crash-recovery row and the README say the folder is
  refused and left for the user.
- **C4 is two commits.** A refactor with no behavior change comes first, carrying only what C3's
  behavior uses: no `Switch` step and no uuid until C4 calls them, and C3's tests stay green
  unchanged. C4 then holds the switch, its tests, the spike doc and C4's docs.

## Order

1. Stash the C4 work. Rework the third C3 commit (the branch tip) test-first and amend it. Copy
   the updated plan and this handoff from the primary worktree into the build worktree and fold
   them into C1. Re-apply the stash on top, dropping its recreated-unit path; leave it
   uncommitted.
2. Stash again. Build the refactor commit on the tip from the stash's restructuring and commit it.
   Re-apply the stash.
3. Finish C4's docs and commit C4.
4. Build C5 as planned.
